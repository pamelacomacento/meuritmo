# Meu Ritmo — V2

Protótipo funcional de produtividade pessoal inspirado em recursos de apps modernos de tarefas, mas com identidade e fluxo próprios.

## Já funciona
- Hoje com sugestão por tempo disponível
- Tarefas com duração, horário, prioridade, categoria, lista, tags, repetição, notas e checklist
- Calendário: mês, semana e agenda
- Hábitos com meta diária e histórico de 7 dias
- Visualizações de tarefas: lista, kanban e linha do tempo
- Matriz de Eisenhower
- Foco/Pomodoro
- Contagens regressivas
- Banco de ideias separado de tarefas
- Ritmo com Semana / Mês / Ano e comparação com período anterior
- Pulso das áreas e tempo investido
- Cor principal e nome do app editáveis no Perfil
- Salvamento local no navegador via localStorage

## Rodar
```bash
npm install
npm run dev
```
Abra http://localhost:3000
